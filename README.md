Salesforce Automation Scripts

This repository contains Salesforce automation and DevOps utility scripts created for learning, process optimization, and CI/CD support.

The projects included here focus on improving deployment workflows, reducing manual effort, and automating Salesforce administrative operations.

---

🚀 Projects Included

1️⃣ Pull Request Test Class Automation

Automation solution that identifies modified Apex classes and automatically attaches corresponding test classes to Pull Request descriptions.

### Features
- Detects modified Apex classes
- Maps corresponding test classes
- Improves CI/CD validation readiness
- Reduces manual deployment effort

---

2️⃣ Salesforce User Creation Automation

Automation script for creating Salesforce users with predefined roles, profiles, and permissions.

### Features
- Automated user creation
- Standardized role/profile assignment
- Simplified onboarding process

---

# 🛠 Technologies Used

- Salesforce DX (SFDX)
- Git & GitHub
- Automation Scripts
- CI/CD Workflow Support
